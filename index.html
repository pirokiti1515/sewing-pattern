ツール

左のツールバーから選びます。▸ が付いているものは、押すと中身が開きます。

✛ ポイント ▸点を足したり、角と丸を切り替えたり
✏️ ペンクリック＝角、ドラッグ＝曲線で自由な形を描く
▭ 図形 ▸四角・丸・左右対称（ドラッグ、または寸法を入力して作成）
📏 計測 ▸寸法線・長さ・アールを測る
T 文字文字を入れる（縦書き対応）
🧵 ステッチ辺をクリックすると内側に平行な点線。自由な線も引ける
⛓ ファスナー歯とスライダー付きのファスナーを描く
↗ 矢印地の目や引き出し線
⊹ 合印輪郭に合印を付ける

✛ ポイント の中身

◆ 角を足す辺の押した場所に、とがった点を足す
◗ 丸を足す辺の押した場所に、なめらかな点を足す（形は変わりません）
◇ 中間選んだ点と点の間に足す（形は変わりません）
⇆ 切替点をクリックすると 角 ↔ 丸 が入れ替わる
✛ 座標距離を指定して点を足す

✛ 座標 の使い方：①基準にする点をクリック → ②置きたい向きへマウスを動かす （緑の破線が伸び、長さが出ます）→ ③距離を打って Enter。
打たずにクリックでもOK。マイナスを入れれば反対向き。 点はパーツの線の上にだけ置けます（届かない位置では破線が灰色になります）。

◫ 左右対称

図形メニューの ◫ 左右対称 で描くと、片側を直すと反対側も鏡のように直ります。 点を動かす・曲線の腕を動かす・合印を入れる、いずれも左右そろいます。

選んでいる間、真ん中にピンクの破線で軸が出ます。 すでに描いてあるパーツも、右クリックの「◫ 左右対称にする」で後から対称にできます（今の真ん中が軸になります）。 やめたいときは同じ場所から解除します。

📏 計測 の中身

📏 寸法線2点をドラッグして寸法を図面に入れる
〰 周長輪郭に沿った長さ（①始点 → ②通り道 → ③終点 の順にクリック）
↔ 直線2点をまっすぐ結んだ距離
◜ アール曲がった辺の半径（R）

測った値は「図面に書き込む」で寸法線として残せます。 書き込んだものを右クリックすると、1つだけ／全部まとめて消せます。

⌒ 接円弧

丸めたい角をクリックしてから、上のバーの半径を動かします。 先に半径を決めておけば、角をクリックしていくだけで次々に丸められます。 ドラッグで囲めば複数の角をまとめて選べます。

選択ツールの操作

  • パーツをクリック … まるごと選択・移動
  • 白い■（点）をドラッグ … その点だけ移動
  • オレンジ●（辺の中央）をクリック … その辺を選ぶ（上のバーで角度と長さを数字で変えられます）
  • オレンジ●（辺の中央）をドラッグ … 辺ごと動かして長さを変える
  • 点をダブルクリック … 角 ↔ 曲線
  • Shift+クリック … 点を追加
  • 右クリック … 色の変更・複製・削除
  • 2つ以上まとめて選択 … 周りに □ が出て、つかむと全体の大きさを変えられる （Shift を押しながらだと縦横の比率が変わりません）
  • 文字をクリック … 上のバーで 字体・大きさ・色・太字・縦書き を変更できる
  • ⌘A … 全部選ぶ（囲む必要がありません）
  • 矢印キー ← → ↑ ↓ … 選んでいる点・パーツを、決めた距離だけ動かす

複数のパーツを囲んで選ぶとき：端がはみ出したパーツも、自動でまるごと選ばれます。 一部の点だけ選ばれた状態で動かすと、そのパーツだけ引き伸ばされて形が変わってしまうためです。 1枚の中だけを囲んだときは、点を選んで形を直す使い方なのでそのままです。 （はみ出したぶんも点のまま選びたいときは、Alt を押しながら離してください）

レイヤーと色（右のパネル）

色と不透明度：パーツを選ぶと使えます。複数選べばまとめて変わります。

  • 線 … 輪郭の色
  • 塗り … 中の色（線とは別に指定できます）
  • 塗りなし … 塗りを消す／戻す
  • 不透明度 … パーツ全体の透け具合
  • 塗りの濃さ … 塗りだけの濃さ

レイヤー：「＋追加」で増やせます。レイヤーをクリックすると、そこが新しく描くものの行き先になります。

  • ▼ … 開く・閉じる
  • 👁 … 表示・非表示（レイヤーごと／パーツ1つだけ、どちらも）
  • 不透明度 … レイヤーごと
  • ⋮⋮ をドラッグ … 並び替え（前後関係も変わります。別のレイヤーへも移せます）

グループ化したものは 🔗 の行にまとまり、名前を付けたり、まとめて表示・非表示にしたり、⛓ で解除したりできます。

⊖ 切り抜く（パーツの足し引き）

パーツを2枚選ぶと、上のバーに ⊖ ⊗ ⊕ が出ます（右クリックからも選べます）。

2枚の選び方：1枚をクリック → もう1枚を ⌘+クリック（Windowsは Ctrl+クリック）。 何もない所からドラッグして囲んでもかまいません。ステッチ線などが一緒に選ばれていても大丈夫です。

  • ⊖ 切り抜く … 上にあるパーツの形で、下のパーツを抜きます
  • ⊗ 重なった所だけ残す … 2枚が重なっている部分だけにします
  • ⊕ 1枚につなげる … 2枚を1枚の形にします

刃にしたパーツ（上にあるほう）は消えます。名前・色・ステッチは下のパーツのものが残ります。 ただし片方がもう片方の中にすっぽり入っているときは、上下に関わらず 「大きいほうから小さいほうを抜く」形になります（そうしないと全部消えてしまうため）。

切った結果が2枚に分かれたときは、そのまま2枚のパーツになります（名前に「（分かれ）」が付きます）。

真ん中をくり抜いた穴は、そのパーツの一部になります。中が本当に抜けて下が透けて見え、 パーツを動かす・回す・反転する・拡大する・複製すると穴も一緒についてきます。 穴をやめたいときは右クリックの「⬜ 穴を埋める」で消せます。

穴の形も、外枠とまったく同じように変えられます。 白い■をドラッグ／ダブルクリックで角↔曲線／曲線の腕（オレンジ）をドラッグ／ オレンジ●（辺の中央）をドラッグして辺ごと動かす／Shift+クリックで点を足す／Delete で点を消す／ ⌒接円弧で角を丸める、が全部使えます。 穴のふちの点を全部消すと、その穴だけが無くなります。

曲線は曲線のまま、少ない点で作り直されます。 たとえば角丸のパーツを切ると22点ほど、円を半分に切ると6点ほどで、あとから形を直しやすい状態です。 ズレは0.1mm程度なので寸法に影響はありません。思ったとおりにならなかったら ⌘Z で戻せます。

← → 選んだものを数字で動かす

点やパーツを選ぶと、上のバーに 移動 [ ]mm と ← → ↑ ↓ が出ます。 距離を入れてボタンを押すと、その向きへぴったりその距離だけ動きます。 キーボードの矢印キーでも同じように動きます。

  • Shift+矢印 … 10倍の距離（10mmなら100mm）
  • Alt+矢印 … 10分の1の距離（10mmなら1mm）で微調整

点を1つだけ選べばその点だけ、パーツごと選べばまるごと動きます。 曲線の曲がり方・合印・穴・文字も一緒についてきます。 左右対称のパーツなら、反対側も鏡になって動きます。

∠ 辺の角度・長さを数字で決める

パーツを選んでから、オレンジ●（辺の中央）をクリックすると、その辺が青く光ります。 上のバーに∠角度と長さの欄が出るので、数字を打つか▲▼で変えられます。

角度は 0°＝右向き、90°＝上向き、180°＝左向き、−90°＝下向きです。

白い○が付いているほうが動かさない側で、そこを軸に辺が回ります。 ◐ 始点を固定のボタンで、どちらを固定するか入れ替えられます。

曲がった辺なら、曲がり方もそのまま一緒に回ります。 左右対称のパーツでは、反対側の辺も鏡になって動きます。 やり直したいときは ⌘Z で戻せます。

辺をそのまま平行に動かすには、移動の欄に距離を入れてボタンを押します。

  • ← → ↑ ↓ … その向きへ、入れた距離だけ動かします
  • ⊥外 / ⊥内 … 辺に直角に、外側／内側へ動かします（幅を広げる・狭めるのに便利）

両端の点が同じだけ動くので、辺の角度と長さは変わりません。 曲がり方も、辺に付いている合印もそのままです。

🧮 かんたん計算機

選択ツールにして何も選んでいないとき、上のバーに計算機が出ます。 式を打って Enter を押すと答えが出て、そのままコピーされます。 （寸法の足し引き、半分の計算などにどうぞ）

  • 例：450-10-10（両側の縫い代を引く）、(1800-30)/2（半分）
  • ＋ − × ÷ とかっこが使えます（×は * や ÷、全角の数字でもOK）
  • 📋 コピーボタン、または答えの欄をクリックでもコピーできます
  • ✕で消せます

スナップ（格子への吸着）

スナップは、格子の線の近くに来たときだけ吸い寄せます。 それ以外はマウスにそのままついてくるので、動きはなめらかなままです。

格子10mmなら、線から±2.5mm以内で吸い寄せます。 たとえば809.5mmの位置で止めると810mmにきっちり乗り、805mmの位置ならそのまま805mmに置けます。

まったく吸着させたくないときはスナップのチェックを外してください。 吸着の刻みを変えたいときは、右クリックのメニューで格子の数字を変えます。

🧲吸着は別のはたらきで、他のパーツの角や辺にぴたっと合わせるためのものです。 こちらも近づいたときだけ効きます。

画面を動かす

⚙ 設定（≡ メニュー）

これから新しく作るものの初期値を決められます。すでに描いてあるものは変わりません。

  • パーツ … 線の色・塗りの色・塗りの濃さ・線の太さ（塗りなしも選べます）
  • 文字 … 字体・大きさ・色・太字・縦書き
  • その他 … 格子の間隔・ステッチの距離・ファスナーの歯・接円弧の半径

決めた設定はこのブラウザに覚えられ、次に開いたときもそのままです。 「はじめの設定に戻す」で元に戻せます。

印刷

「≡ メニュー → 🖨 印刷」（⌘P）でプレビューが開きます。 用紙サイズと向きを選ぶと、その紙に収まるように自動で縮小されます。

ソファーの図面は1800mmなどになるため実寸では紙に載りませんが、 寸法線の数字は実寸のまま入り、用紙を変えても数字の大きさは変わらないので読めなくなりません。

PDFで保存：同じ画面の「📄 PDFで保存」を押すと印刷の画面が開くので、 送信先を「PDFに保存」に変えてください。用紙サイズや向きの設定はそのまま効きます。

📚 図面の一覧

「≡ メニュー → 📚 図面の一覧」で、フォルダの中の図面が縮小図で並びます。 クリックするだけで開けるので、ファイルを探す手間がなくなります。

  • はじめに一度だけ📁 フォルダを選ぶ（図面を入れてあるフォルダ）
  • 次からは開くだけで並びます。新しく保存した順に上から出ます
  • 上の欄に名前を打つとしぼりこみできます
  • 🔄 更新で読み直し。別のパソコンで保存した図面も出てきます

一覧から開いた図面はそのまま保存先になります。直して「💾 保存」を押せば、 そのファイルに上書きされます（どのファイルに保存されるかは上のバーに 📄 で出ます）。

フォルダの中身は、このパソコンの中だけで読まれます。どこにも送信されません。 許可はこのブラウザだけのもので、他の人がURLを開いても、その人自身のフォルダしか選べません。 やめたいときは🚫 記憶を消すを押してください（フォルダの中の図面は消えません）。

※ Chrome・Edge で使えます。Safari では一覧が出ないので「📂 開く（1つずつ）」をお使いください。

保存について

描いた図面はブラウザに自動保存されますが、ブラウザのデータを消すと失われます。 大事な図面は「≡ メニュー → 💾 保存」でファイルに保存してください。読み込みは「📂 開く」です。

💾 保存 は上書きです。はじめの1回だけ保存先を聞かれ、 次からは同じファイルに上書きされます。いま保存される先は、上のバーに 📄 ファイル名 として出ています。別のファイルにしたいときは 💾 別名で保存… を使ってください。

「📂 開く」で開いたファイルは、そのまま保存先になります。 新規作成すると保存先は忘れるので、別の図面を上書きしてしまう心配はありません。

※ Safari など一部のブラウザは上書きに対応していません。その場合は今まで通り ダウンロードになり、同じ名前で保存すると「○○ (1).json」のように 別のファイルが増えていきます。開き直すときは、いちばん新しいものを選んでください。

図面はこのパソコンの中だけに保存され、どこにも送信されません。 URLを人に渡しても、相手には空の画面が開くだけで、あなたの図面は見えません。 （同じパソコンの同じブラウザを他の人が使う場合は見えます）

「保存したのに無い」ときは、開き場所が違うことが多いです。 自動保存は開いている場所ごとに別々になります。 ネット（https://…）で開いたときの図面と、パソコンの中のファイルを直接開いたときの図面は、 別々に保存されるため、片方で描いたものはもう片方には出てきません。 ブラウザを変えたときも同じです。

いつも同じ場所から開くようにするか、行き来するときは 「💾 保存」でファイルにしてから「📂 開く」で読み込んでください。

自動保存ができない状態のときは、上のバーに⚠ 自動保存できませんと出ます。 これが出ているときは、必ずファイルに保存してください。
